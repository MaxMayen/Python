PYTHON (PYTHON 3.12)



Estructura y Definiciones

•def: Define una función

•class: Define una clase (POO).

•import / from: Carga módulos o librerías externas.

•as:Crea un alias para un módulo (ej. import pandas as pd).

•return: Devuelve un valor en una función.

•yield: Pausa una función y devuelve un valor (generadores).

•lambda: Crea una función anónima rápida de una sola línea.

•pass: Una operación nula; se usa cuando el código requiere una sentencia pero no quieres hacer nada.

•global / nonlocal: Declara que una variable pertenece aun ámbito superior.



Control de Flujo y Lógica

•if / elif / else: Condicionales.

•for: Bucle para iterar sobre secuencias (listas, rangos).

•while: Bucle que se ejecuta mientras la condición sea verdadera.

•break: Sale del bucle actual.

•continue: Salta a la siguiente iteración del bucle.

•in: Verifica si un elemento está en una secuencia.

•is: Verifica si dos variables apuntan al mismo objeto.

•and / or / not: Operadores lógicos.

•match / case: Control del flujo por patrones (Python 3.10+).



Tipos de Datos y Estructuras

•int / float / complex: Números enteros, decimales, y complejos.

•str: Cadena de texto (String).

•bool: Valores True o False.

•list: Lista mutable (modificable) entre corchetes [].

•tuple: Tupla inmutable entre paréntesis ().

•dict: Diccionario de clave-valor entre llaves {}.

•set: Conjunto de elementos únicos.

•None: Representa la ausencia de valor (como el null de Java).



Manejo de Errores (Excepciones)

•try: Bloque para probar código con posibles errores.

•except: Bloque que atrapa y maneja el error.

•finally: Código que se ejecuta pase lo que pase.

•raise: Lanza una excepción manualmente.

•assert: Se usa para depuración; verifica si una condición es cierta.



Contexto y Asincronia

•with: Maneja contextos (como abrir archivos) asegurando que se cierren solos.

•async / await: Define y maneja funciones asíncronas (corrutinas).

•del: Elimina una referencia a un objeto o elemento.
